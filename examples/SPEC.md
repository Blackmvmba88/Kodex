# SPEC: Example App MVP

## Product

Build a tiny local-first task tracker.

## Users

- Creator working from terminal
- Developer reviewing generated changes

## MVP Features

- Create a task
- List tasks
- Mark task done
- Store data locally as JSON
- Provide CLI help

## Non-goals

- No cloud sync
- No auth
- No database server
- No automatic publishing

## Acceptance Criteria

- CLI command exists
- Unit tests pass
- README documents usage
- No secrets are written
- All changes are reviewed before commit
